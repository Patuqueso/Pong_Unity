# Pong

A recreation of the classic Pong arcade game built in **Unity 6** as part of my personal game development challenge.

<p align="center">
  <img src="Media/pong.gif" alt="Pong Gameplay" width="700">
</p>

## Features

- 🏓 Two-player local multiplayer
- ⚪ Ball with randomized serves
- 📐 Dynamic paddle bounce angles based on where the ball hits
- 🧱 Wall collisions using vector reflection
- 🎯 Goal detection and score tracking
- 📢 Event-driven scoring system using C# events
- 🔄 Ball reset after each goal

## Controls

| Player | Up | Down |
|--------|----|------|
| Player 1 | W | S |
| Player 2 | ↑ | ↓ |

## Built With

- Unity 6
- C#
- TextMesh Pro

## What I Learned

This project helped me practice:

- Unity's 2D physics system
- Rigidbody2D movement and collision handling
- Computing custom bounce angles for gameplay
- Event-driven programming using C# events
- Organizing gameplay logic with a Game Manager
- Building a complete game loop from scratch
